# Freeisland V0.0.2 版本功能说明（待审核）

> 状态：**草稿，待用户审核**。审核通过后才随代码一并提交到 GitHub。
> 基线：F-904 v6 / A6（仓库原基线），版本标记由 `V0.01.x` / `A6` 起改为 `V0.0.2.<构建序号>`。
> 日期：2026-11-27

## 一、版本定位

V0.0.2 是 **IPv6 私有 DHT 双向消息打通版**。在完全没有 `bootstrap.jami.net`（纯私有 DHT、仅靠名片好友关系）的前提下，两个异地节点通过 IPv6 建立了 DHT 链路并完成双向文字消息收发。

## 二、核心功能

### 1. IPv6 私有 DHT 双栈绑定（P6）
- `initDhtConfig()` 用 `SockAddr::resolve()` 设置 `config.bind4/bind6`；私有 DHT 账号改用 `dht_->run(config, context)` 重载（`run(port, ...)` 会覆盖 bind6）。
- Windows 由 `JAMI_P6_DHT_IPV6=1` 控制；Android 默认开启。
- `JAMI_P6_BIND_IP6` 指定具体 GUA 绑定，规避"多运营商 GUA + 绑 `::` 导致回包源 IP 不匹配被移动网络丢弃"的问题。

### 2. 一侧 IP 变化支持（A 方案）
- 新增 `JamiAccount::p6RefreshBootstrap_()`，由 `networkInterfaceChanged()` 触发。
- 固定侧从 `exportNodes()` 学到对端新地址后 `clearBootstrap()` + `bootstrap(id, addr)` 热更新；变化侧只 `bootstrap(addr)` ping 对端，让 OpenDHT 从包源自动学习新地址，不清空 bootstrap。
- 从 DHT 状态回调中移除该调用（回调持 DHT 内部锁，重入会崩溃 `0xC0000409`）。

### 3. 消息可达性修复（本次核心）
- keepalive 默认值与注释矛盾：代码两处 `return 5` 改为 `return 30`，避免密集 `connectivityChanged()` 把 DHT 节点打回 dubious、身份公告反复失败。
- **决定性修复**：`identityAnnouncedCb` 在身份公告失败时不再直接 `return`——私有 DHT 下（名片好友已互信，不依赖 DHT announce 验证）继续走 `startSync()`，发布 presence/device 并 listen。此前手机跳过 `startSync()`，PC 永远看不到手机在线，消息全部卡 pending。
- 修复后证据链：PC `presencePut OK h=96327eb...`、手机 `Buddy 96327eb... online`、手机 `forEachDevice END ok=1 n=1`（发现 PC 设备），双向消息落库/可见。

### 4. About 页版本显示规则（本次约定）
- 显示格式：`Freeisland V0.0.2.<构建序号>`。
- 构建序号在版本号后附加，**每次成功编译 +1**。
- Qt 端：构建序号由 `extras/build/cmake/generate_version_info.cmake` 维护（build 树 `freeisland_build_number.txt` 每次 configure +1），AboutPopUp.qml 拼接显示。
- Android 端：`freeisland_version` 字符串由构建脚本在编译前递增末尾序号（初始 1）。
